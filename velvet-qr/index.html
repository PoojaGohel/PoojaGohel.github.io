🔳 Velvet QR

Velvet QR

Customizable QR code generator for React applications. Type something below to generate a live QR code.

Live preview generated via a public QR API — the real package renders QR codes locally with logos, gradients, and export options.

Install

npm i velvet-qr

Quick Start

import { VelvetQR } from 'velvet-qr';

export default function App() {
  return <VelvetQR value="https://poojagohel.github.io" />;
}
