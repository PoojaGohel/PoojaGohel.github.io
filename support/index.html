Frequently asked questions

Where do I report a bug?

Open an issue on the relevant package's GitHub repository so it's tracked alongside the source code and visible to other users hitting the same problem.

Which React versions are supported?

All VelvetJS packages support React 18 and React 19, with TypeScript types included out of the box.

Is VelvetJS free to use?

Yes — every package is open-source and MIT licensed, free for personal and commercial projects.

How fast will I get a response?

VelvetJS is maintained by a single person in their spare time. There's no SLA, but GitHub issues and emails are checked regularly.
